확률과 통계
기초 선형 모델
최소제곱 직선을 여러 공변량과 오차항을 가진 선형 모델로 넓혀, 추정과 추론, 범주형 변수와 비선형 효과, 모델 진단과 모델 선택, 랜덤 효과와 일반화 선형 모델까지 다루는 기초 선형 모델 과목의 내용과 성격, 사전 지식을 소개합니다.
Published

November 18, 2026

같은 넓이, 다른 월세

새로 이사할 집을 찾는다고 해 보겠습니다. 부동산 매물 목록을 훑다 보면 금방 눈치채는 사실이 있습니다. 넓은 집일수록 월세가 비쌉니다. 그런데 넓이가 똑같은 두 집의 월세가 꽤 다른 경우도 흔합니다. 한 집은 지은 지 50년이 넘었고 다른 집은 새 건물이거나, 한 집은 조용한 주택가에 있고 다른 집은 시내 한복판에 있을 수 있습니다.

기초 통계학에서 배운 최소제곱 직선으로는 “넓이가 1㎡ 넓으면 월세가 평균적으로 얼마 더 비싼가”까지는 답할 수 있습니다. 하지만 정말 궁금한 질문은 대개 그다음에 나옵니다.

  • 넓이가 같다면, 위치가 좋은 집은 월세가 얼마나 더 비쌀까요?
  • 넓이에 따라 월세가 늘어나는 정도가 위치마다 다를까요?
  • 넓이가 늘어날 때 ㎡당 월세는 일정하게 줄어들까요, 아니면 어느 넓이부터는 거의 그대로일까요?
  • 우리가 계산한 차이는 진짜 차이일까요, 아니면 하필 이 집들이 표본으로 뽑혀서 생긴 우연일까요?
  • 애초에 우리가 세운 모형은 데이터와 맞기는 할까요?

이런 질문에 답하려면 직선 하나로는 부족합니다. 여러 요인을 한꺼번에 담고, 그 요인들로 설명되지 않는 흩어짐까지 확률로 다루는 틀이 필요합니다. 그 틀이 선형 모델(linear model)입니다.

선형 모델이 하는 일

선형 모델은 관심 있는 변수 \(y\)(월세)를 여러 변수 \(x_1, \ldots, x_k\)(넓이, 건축 연도, 위치 등)로 설명합니다. 식으로 쓰면 다음과 같습니다.

\[y = \beta_0 + \beta_1 x_1 + \cdots + \beta_k x_k + \varepsilon\]

앞부분 \(\beta_0 + \beta_1 x_1 + \cdots + \beta_k x_k\)는 공변량으로 설명되는 부분이고, 마지막의 \(\varepsilon\)은 설명되지 않고 남는 부분입니다. 선형 모델의 핵심은 이 남는 부분을 그냥 버리지 않고 확률변수로 다룬다는 데 있습니다. 그래야 “이 계수가 0이 아니라고 얼마나 확신할 수 있는가” 같은 질문을 확률의 언어로 답할 수 있습니다.

모양은 단순하지만 선형 모델은 놀라울 만큼 많은 곳에서 쓰입니다. 집의 특성으로 월세를 설명하는 임대료 지표, 교육과 경력으로 임금을 설명하는 노동 경제학, 연식과 주행 거리로 중고차 가격을 설명하는 일, 가정 환경으로 아이들의 영양 상태를 설명하는 보건 연구가 모두 선형 모델에서 출발합니다. 그리고 이름과 달리 선형 모델은 곡선 관계, 범주형 변수, 변수 사이의 상호작용까지 담을 수 있습니다. 무엇에 대해 “선형”인지는 1장에서 자세히 살펴봅니다.

이 과목에서 다루는 것

기초 선형 모델은 최소제곱 직선에서 출발해, 선형 모델을 세우고 추정하고 추론하는 방법, 모델이 데이터에 맞는지 점검하고 여러 모델 중에서 고르는 방법, 그리고 선형 모델의 대표적인 확장까지를 다룹니다. 전체는 다음 여섯 개의 장으로 이루어집니다.

  1. 선형 모델과 최소제곱 추정: 최소제곱 직선을 반응변수, 공변량, 회귀계수, 오차항으로 이루어진 선형 모델로 넓히고, 오차항에 대한 가정과 계수의 해석, 행렬 표현, 최소제곱 추정량과 그 성질, 그리고 최소제곱법을 사영으로 보는 기하학적 관점을 다룹니다.
  2. 선형 모델에서의 추론: 회귀계수의 신뢰구간과 t-검정, 여러 계수를 한꺼번에 검정하는 F-검정과 분산분석표, 다중 검정과 신뢰 타원, 새 관측값에 대한 예측구간을 다룹니다.
  3. 설명변수 다루기: 범주형 공변량을 모델에 넣는 더미 코딩과 효과 코딩, 교호작용과 이원 분산분석, 그리고 변환, 다항식, 스플라인으로 비선형 효과를 표현하는 방법을 다룹니다.
  4. 모델 진단: 여러 종류의 잔차와 잔차 그림으로 오차항에 대한 가정을 점검하고, 이분산, 상관된 오차, 정규성 위반, 공선성, 이상치와 영향점을 찾아내고 다루는 방법을 살펴봅니다.
  5. 모델 선택과 정규화: 공변량을 빠뜨리거나 너무 많이 넣으면 무슨 일이 생기는지 살펴보고, 정보 기준과 교차 검증으로 모델을 고르는 방법, 변수 선택 전략, 그리고 릿지와 라쏘 같은 정규화 방법을 다룹니다.
  6. 선형 모델의 확장: 같은 사람을 여러 번 관측한 데이터처럼 군집을 이루는 데이터를 위한 랜덤 효과 모델, 그리고 반응변수가 0과 1이거나 개수일 때 쓰는 일반화 선형 모델을 소개합니다.

이 과목의 성격

기초 선형 모델은 선형 모델을 처음 만나는 분을 위한 과목입니다. 그래서 다음과 같은 방향으로 진행합니다.

  • 직관과 실제 데이터가 먼저입니다. 정의와 정리는 정확하게 적지만, 그 결과가 왜 자연스러운지를 시뮬레이션과 실제 데이터로 먼저 보여 드립니다. 1999년 뮌헨의 임대료 조사, 골턴의 부모·자녀 키 데이터처럼 공개된 데이터를 쓰고, 모든 계산은 파이썬(NumPy, pandas, statsmodels)으로 직접 실행한 결과를 싣습니다.
  • 증명은 짧게, 또는 링크로 대신합니다. 짧고 아이디어가 잘 드러나는 증명은 접힌 상자에 넣어 두고, 길거나 기술적인 증명은 생략합니다. 같은 내용을 수학적으로 더 엄밀하게 다루는 과목으로는 수리적 데이터 분석과 통계적 추론과 데이터 사이언스의 통계적 기초가 있습니다. 증명이 궁금하신 분은 그쪽으로 안내해 드리겠습니다.
  • 기초 통계학에서 이어집니다. 최소제곱 직선, 결정계수, 점 추정, 신뢰구간, 가설 검정, 모델 선택처럼 기초 통계학에서 배운 도구들이 선형 모델 안에서 어떻게 다시 쓰이는지를 계속 짚어 드립니다. 표기도 기초 통계학을 바탕으로 하되, 회귀계수를 \(\beta_0, \beta_1, \ldots\)로 쓰는 것처럼 선형 모델에서 널리 쓰이는 표기를 따릅니다.

읽기 전에: 필요한 사전 지식

기본으로 전제하는 것

  • 기초 통계학: 평균과 분산, 상관계수, 최소제곱 직선과 결정계수, 그리고 추정량, 신뢰구간, 가설 검정의 기본 개념을 알고 있다고 가정합니다. 특히 최소제곱 직선을 다룬 4.5절이 이 과목의 출발점입니다.
  • 행렬의 기초 연산: 행렬의 곱, 전치, 역행렬, 그리고 행렬의 계수(rank)가 무엇인지 정도를 알면 됩니다. 1.3절에서 필요한 만큼 짧게 복습합니다. 더 체계적으로 공부하고 싶으신 분은 선형대수학을 참고하시기 바랍니다.

있으면 좋은 것

  • 기초 확률론: 기대값, 분산, 공분산, 정규분포의 성질을 자유롭게 쓸 수 있으면 1장 후반부와 2장이 훨씬 수월합니다.
  • 수학적 프로그래밍의 파이썬 기초: 글마다 코드와 실행 결과를 함께 싣습니다. 코드를 직접 돌려 보시면 좋지만, 코드를 건너뛰고 결과 숫자와 그림만 따라가셔도 흐름을 이해하는 데에는 지장이 없습니다.

이 과목 다음에는

  • 통계적 모델링: 실제 데이터에 맞는 모형을 세우고 다듬는 과정을 더 넓은 모형들로 확장합니다.
  • 수리적 데이터 분석과 통계적 추론: 이 과목에서 직관적으로 넘어간 선형 모델의 성질을 조건부 기대값과 사영의 언어로 엄밀하게 다시 세웁니다.
  • 시계열 분석의 통계적 기초: 4장에서 맛보는 “오차가 서로 상관된 경우”가 시계열 데이터에서는 출발점이 됩니다.
  • 머신러닝: 5장의 교차 검증과 정규화는 머신러닝에서 모델을 고르고 다듬는 기본 도구이기도 합니다.

근데 여기서 꼽은 과목들도 일부입니다. 선형 모델은 사실상 모든 통계, 데이터 사이언스 과목과 연결된다고 하는게 더 적절해보입니다. 단지 지금 제가 당장 떠올릴 수 있는 목록이 이 정도라고 생각하시면 되겠습니다.
