데이터 사이언스와 통계학은 닮았습니다

데이터 사이언스 개론에서 다루는 것처럼, 데이터 사이언스는 데이터 그 자체로부터 의미 있는 무언가를 이끌어 내기 위한 방법론들의 학문입니다. 고객의 구매 기록으로 다음 달 매출을 예측하고, 사진 수만 장으로 고양이와 개를 구분하는 법을 배우고, 환자들의 검사 수치로 질병의 위험 요인을 찾아냅니다.

이 목적은 통계학의 목적과 매우 닮아 있습니다. 통계학은 본질적으로 우리 손에 주어진 일부의 데이터, 즉 표본(sample)으로부터 우리가 정말로 알고 싶은 전체, 즉 모집단(population)에 대해 무언가를 알아내려는 학문입니다. 선거 여론조사가 대표적인 예입니다. 전국의 유권자 수천만 명에게 모두 물어볼 수는 없으니, 천 명 남짓에게 물어본 결과로 전체 유권자의 지지율을 추정합니다. 현대 통계학의 기틀을 놓은 피셔(R. A. Fisher)도 1922년의 논문에서, 통계적 방법의 목적을 방대한 데이터를 그 전체를 잘 대변하는 몇 개의 수치로 줄이는 것으로 보았고, 이때 실제 데이터는 가상의 무한한 모집단에서 뽑힌 표본으로 간주된다고 설명했습니다.1

데이터 사이언스도 사정이 다르지 않습니다. 모델을 만들 때 쓰는 데이터는 언제나 유한하고, 우리가 정말로 관심 있는 것은 아직 보지 못한 데이터에서도 모델이 잘 작동하는지입니다. 다음 달의 매출은 아직 일어나지 않았고, 모델이 앞으로 판별할 사진은 아직 찍히지도 않았습니다. 즉 데이터 사이언스 역시 “가진 데이터로부터 보지 못한 전체를 이야기하는” 일을 하고 있는 셈입니다.

이런 이유로 데이터 사이언스에서 다루는 모델들의 밑바탕에 깔린 아이디어는 대부분 통계학에서 나왔습니다. 데이터 사이언스 개론에서 다루는 회귀(regression)와 분류(classification)가 대표적인 예입니다.

수리통계학자에게는 조금 아픈 이야기

물론 수리통계학을 공부하는 사람이라면 솔직하게 인정해야 할 부분이 있습니다. 오늘날 데이터 사이언스의 주류를 이끄는 것은 통계적 방법론 그 자체라기보다는, 그 방법론을 실제로 적용하는 순간 생기는 문제들을 해결하는 분야들입니다. 데이터가 수억 개로 늘어나거나 변수가 수만 개가 되면, 교과서에서는 공식 한 줄로 끝나던 계산도 현실적으로 불가능해집니다. 이런 문제를 풀어 방법론을 더 크고 빠르고 정확하게 응용할 수 있게 해 주는 수치적 방법론, 수학적 최적화, AI 컴퓨팅 같은 분야가 지금 데이터 사이언스의 메인스트림을 차지하고 있습니다.

그렇다고 통계가 뒤로 물러난 것은 아닙니다. 아무리 화려한 모델이라도 그 밑을 파고 들어가면 결국 통계적 아이디어가 나옵니다. 예를 들어 딥러닝에서 분류 모델을 학습시킬 때 표준처럼 쓰는 교차 엔트로피 손실(cross-entropy loss)을 최소화하는 것은, 통계학의 최대우도 추정(maximum likelihood estimation)을 그대로 옮겨 놓은 것입니다. 회귀에서 흔히 쓰는 제곱 오차 손실을 최소화하는 것 역시, 오차가 정규분포를 따른다고 가정했을 때의 최대우도 추정과 같습니다.

그래서 최적화나 AI 컴퓨팅 쪽에 무게를 두고 데이터 사이언스를 공부하더라도, 그것을 뒷받침하는 통계적 아이디어를 이해하는 것은 여전히 중요합니다. 모델이 무엇을 추정하고 있는지, 왜 그 손실 함수를 최소화하는 것이 합리적인지, 그리고 그 결과를 얼마나 믿을 수 있는지에 대한 답은 통계학에서 나오기 때문입니다.

직선 하나에 숨어 있는 질문들

간단한 예로 이 차이를 느껴 보겠습니다. 데이터 사이언스 개론 수준에서 선형 회귀는 대략 이렇게 설명됩니다. “점들이 흩어져 있을 때, 각 점에서 직선까지의 세로 거리를 제곱해서 더한 값이 가장 작아지는 직선을 찾는다.” 이것이 최소제곱법(least squares method)이고, 이렇게 찾은 직선이 데이터를 가장 잘 설명하는 직선이라고 배웁니다.

그런데 통계학자의 눈으로 보면, 우리가 가진 점들은 모집단에서 뽑힌 하나의 표본일 뿐입니다. 표본을 새로 뽑으면 점들도 바뀌고, 당연히 직선도 바뀝니다. 직접 확인해 보겠습니다. 아래 코드는 참된 관계가 \(y = 1 + 2x\)인 모집단에서, 잡음이 섞인 점 30개짜리 표본을 다섯 번 새로 뽑아 매번 최소제곱 직선을 구합니다.

import numpy as np

np.random.seed(1557)
for i in range(5):
    x = np.random.rand(30)                       # 설명변수 30개
    y = 1 + 2 * x + 0.5 * np.random.randn(30)    # 참모형: y = 1 + 2x + 잡음
    slope, intercept = np.polyfit(x, y, 1)       # 최소제곱 직선
    print(f"표본 {i + 1}: 절편 = {intercept:.3f}, 기울기 = {slope:.3f}")
표본 1: 절편 = 0.935, 기울기 = 2.292
표본 2: 절편 = 1.096, 기울기 = 2.127
표본 3: 절편 = 1.051, 기울기 = 2.043
표본 4: 절편 = 0.987, 기울기 = 2.274
표본 5: 절편 = 1.389, 기울기 = 1.439

똑같은 모집단, 똑같은 방법인데도 기울기가 1.4에서 2.3까지 오르내립니다. 이 예에서는 우리가 데이터를 직접 만들었으니 참값이 2라는 것을 알지만, 현실에서는 참값을 모른 채 단 하나의 표본만 가지고 있습니다. 그렇다면 자연스럽게 이런 질문들이 생깁니다.

  • 최소제곱 직선은 정확히 무엇을 추정하고 있는가? 데이터 뒤에 어떤 모형을 가정하고 있는가?
  • 하나의 표본으로 구한 기울기는 참값에서 얼마나 벗어나 있을 수 있는가?
  • 표본이 커지면 정말로 참값에 가까워지는가? 그렇다면 어떤 의미에서, 얼마나 빨리 가까워지는가?
  • 기울기가 1.4로 나왔다면, “\(x\)와 \(y\) 사이에는 실제로 관계가 있다”고 얼마나 자신 있게 말할 수 있는가?

이 질문들의 핵심에는 한 가지 관점의 전환이 있습니다. 데이터로부터 계산한 기울기는 하나의 고정된 숫자가 아니라, 표본에 따라 값이 달라지는 확률변수라는 것입니다. 이 확률변수가 어떤 분포를 따르는지 알면 위의 질문에 모두 답할 수 있고, 이렇게 표본으로부터 모집단에 대해 근거 있는 결론을 끌어내는 과정을 통계적 추론(statistical inference)이라고 부릅니다.

개론보다 한 걸음 더

이런 이야기는 데이터 사이언스 개론에서도 다룹니다. 다만 개론에서는 수학적인 디테일을 상당 부분 덜어 내고, 휴리스틱(heuristic) 위주로 통계적 아이디어를 설명합니다. 여기서 휴리스틱이란, 아주 단순한 상황만을 가정해서 어떤 방법이 대략 어떤 식으로 작동하는지를 직관적으로 이해하게 해 주는 설명 방식을 말합니다. 입문 단계에서는 이것이 가장 좋은 방법이지만, 그 직관이 정확히 어떤 조건에서 성립하고 어디서부터 깨지는지는 알기 어렵습니다.

이 과목에서는 이 휴리스틱을 조금 더 깊게 파고 들어가서, 통계적 아이디어들이 구체적으로 어떻게 사용되는지를 좀 더 정확하게 다룹니다. 예를 들어 개론에서 말로 했던 설명들은 다음과 같이 수학의 언어로 옮겨집니다.

  • “데이터가 많아지면 추정이 정확해진다” → 표본 크기 \(n\)이 커질 때 추정량 \(\hat{\beta}_n\)이 참값 \(\beta\)로 확률수렴한다는 일치성(consistency): \[\hat{\beta}_n \xrightarrow[n \to \infty]{} \beta \quad (\text{확률수렴})\]
  • “평균적으로는 맞는 답을 준다” → \(\mathbb{E}[\hat{\beta}_n] = \beta\)라는 불편성(unbiasedness)
  • “답이 이 정도 범위 안에 있을 것이다” → 추정량의 분포로부터 만드는 신뢰구간(confidence interval)

이렇게 옮겨 놓으면, 막연하던 직관이 어떤 가정 위에서 성립하는지가 분명해지고, 가정이 깨졌을 때 무엇이 잘못되는지도 따져 볼 수 있게 됩니다.

이 과목의 위치

그렇다고 이 과목이 수리통계학의 모든 디테일을 다루는 것은 아닙니다. 이 과목은 어디까지나 개론 수준의 휴리스틱을 넓혀서 다루고, 거기에 어느 정도의 수학적인 디테일을 덧붙인 것에 가깝습니다.

더 엄밀한 수학적·통계적 디테일은 심화 과목인 데이터 사이언스의 통계적 기초에서 다룰 예정입니다. 그 심화 과목에도 이 과목에서 다루는 내용이 똑같이 등장하므로, 두 과목은 같은 지역을 서로 다른 축척으로 그린 지도라고 생각하시면 됩니다. 처음부터 엄밀한 증명까지 따라가고 싶다면 심화 과목만 선택해서 공부하셔도 되고, 세세한 증명보다는 통계적 모델을 지금보다 정확하게 이해하는 것이 목적이라면 이 과목을 공부하시면 됩니다.

이 과목에서 다루는 것

정리하면, 수리적 데이터 분석과 통계적 추론 과목의 목적은 수리통계학의 아주 세밀한 부분까지 파고드는 것이 아니라, 데이터 사이언스에서 중요한 수리통계 모델들을 휴리스틱을 넘어 수학적 언어로 조금 더 정확하게 표현하고 이해하는 것입니다.

모델이 “잘 작동한다”는 말을 직관으로만 받아들이지 않고, 그 말이 수학적으로 정확히 무엇을 뜻하며 어떤 가정 위에 서 있는지까지 함께 살펴보는 것이 이 과목의 핵심입니다.

읽기 전에: 필요한 사전 지식

이 과목은 다음 과목들의 내용을 알고 있다는 전제에서 출발합니다. 필요한 개념이 나올 때마다 정의와 정리는 다시 적어 두지만, 증명은 대부분 아래 과목의 해당 글을 참고하는 것으로 하고 넘어갑니다.

기본으로 전제하는 과목

  • 해석학: 수열과 함수의 극한, 연속성, 미분. 추정량이 참값에 “가까워진다”는 말은 결국 극한과 수렴에 대한 이야기이고, 손실 함수를 최소화하는 추정량을 구할 때는 미분을 씁니다.
  • 선형대수학: 벡터, 행렬, 내적과 사영. 변수가 여러 개인 회귀 모형은 \(\mathbf{y} = X\boldsymbol{\beta} + \boldsymbol{\varepsilon}\)처럼 행렬로 쓰는 것이 자연스럽고, 최소제곱법은 기하학적으로 사영(projection)으로 이해할 수 있습니다.
  • 측도론: 측도와 르베그 적분. 기대값과 여러 가지 수렴 개념을 정확하게 서술하는 데 쓰입니다.
  • 기초 확률론 또는 측도론적 확률론: 확률변수와 분포, 기대값과 분산, 독립성, 큰 수의 법칙과 중심극한정리. 앞에서 본 것처럼 추정량은 확률변수이므로, 추정량의 성질을 따지는 도구는 모두 여기에서 나옵니다. 기초 확률론만으로도 대부분의 흐름은 따라올 수 있지만, 정리의 정확한 조건과 의미까지 짚고 싶다면 측도론적 확률론을 함께 보시기를 권합니다.

기본 전제라고 해서 위 과목의 내용을 모두 알아야 하는 것은 아닙니다. 그 과목들을 공부하면서 얻은 수학적 사고방식과 직관, 그리고 큼직한 정리들의 결론 정도만 알고 계셔도 이 과목을 공부하는 데에는 큰 무리가 없습니다.

선택 사항

  • 수학적 프로그래밍 (Python): 글마다 파이썬 코드와 그 실행 결과가 함께 실려 있습니다. 코드를 직접 읽고 돌려 볼 수 있다면 훨씬 생생하게 이해할 수 있지만, 몰라도 괜찮습니다. 코드 블록은 건너뛰고, 그 결과로 나온 수치와 그림이 무엇을 보여 주는지만 이해하셔도 내용을 따라오는 데에는 전혀 지장이 없습니다.
  • 데이터 사이언스 개론 또는 기초 통계학: 몰라도 이 과목을 공부하는 데 전혀 지장이 없습니다. 다만 이 과목에서 다룰 내용의 휴리스틱을 미리 알고 있으면, 수식이 무엇을 정확하게 만들려는 것인지 금방 보이기 때문에 이해가 훨씬 빨라집니다. 알고 있으면 좋은 정도로 생각하시면 됩니다.
