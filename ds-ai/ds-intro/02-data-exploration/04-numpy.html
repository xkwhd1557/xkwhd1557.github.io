2.4 NumPy로 데이터 다루기

2장 데이터 탐색: 기술 통계와 시각화 · 수치 데이터를 담는 그릇, 배열

데이터 사이언스·AI
데이터 사이언스 개론
파이썬에서 수치 데이터를 다루는 기본 도구인 넘파이(NumPy)의 배열을 소개합니다. 배열의 모양과 축, 시드, 데이터 검사와 결측치 처리, 배열 연산, 파일로 저장하고 불러오는 방법을 예제로 살펴봅니다.
Published

November 3, 2026

들어가며

2.1부터 2.3까지 기술 통계를 다루면서 계속 넘파이로 계산을 해 왔습니다. 이번 글부터는 그 도구들을 직접 다뤄 보겠습니다. 데이터를 숫자로 요약하든 그림으로 그리든, 파이썬에서 수치 데이터를 다룰 때 거의 모든 작업의 바탕에는 넘파이(NumPy)가 있습니다.

이 글은 기본적인 파이썬 문법(변수, 리스트, 함수, 반복문)을 안다는 전제에서 출발합니다. 파이썬이 처음이시라면 수학적 프로그래밍의 파이썬 기초 부분을 먼저 보시기를 권합니다. 그 과목에서는 파이썬이나 넘파이를 데이터 사이언스뿐 아니라 수학 전반에 쓰는 더 다양한 이야기도 다루는데요, 여기서는 데이터를 다루는 데 꼭 필요한 부분만 골라서 보겠습니다.

넘파이는 뭐고, 왜 쓰나요?

넘파이는 과학적 계산(scientific computing)을 위한 라이브러리입니다. 과학적 계산이란 수학적 모델을 컴퓨터 알고리즘으로 옮겨 과학이나 공학의 문제를 푸는 분야로, 쉽게 말하면 실험을 컴퓨터로 하는 분야입니다. 흔히 말하는 수치적 방법론, 수치해석학, 수치 수학(numerical mathematics)의 또 다른 이름으로 받아들이셔도 됩니다. 이를 위해 넘파이가 제공하는 핵심 도구는 배열(array)입니다.

배열은 그냥 기본적으로 여러 숫자를 한 바구니에 담아 모으는 도구입니다. 그런데 여러 숫자를 한데 모으는 것은 파이썬의 리스트로도 할 수 있는데, 왜 굳이 배열을 사용할까요? 그 이유는 간단합니다. 리스트는 수치 계산에 그리 알맞지 않기 떄문입니다. 구체적으로 들어가서 왜 수치 계산에 적절하지 않은지를 살펴보자면, 두 가지 이유를 꼽을 수 있습니다.

첫째, 속도입니다. 파이썬의 리스트에는 숫자, 문자열, 다른 리스트처럼 서로 다른 종류의 값을 섞어 담을 수 있습니다. 편리한 성질이지만, 수치 계산에서는 오히려 짐이 됩니다. 컴퓨터가 리스트의 원소를 하나 읽을 때마다 “이게 무슨 종류의 값이지?”를 확인해야 하고, 원소들이 메모리 여기저기에 흩어져 있기 때문입니다. 넘파이 배열은 한 가지 종류의 숫자만 담고 메모리에 촘촘하게 붙여 저장하기 때문에, 이런 확인 없이 아주 빠르게 계산할 수 있습니다.

둘째, 연산의 의미입니다. 리스트에도 +와 *를 쓸 수 있지만, 수학에서 생각하는 덧셈과 곱셈이 아닙니다.

lst = [1, 2, 3]
print(lst + lst)
print(lst * 2)
[1, 2, 3, 1, 2, 3]
[1, 2, 3, 1, 2, 3]

리스트끼리 더하면 두 리스트가 이어 붙고, 리스트에 2를 곱하면 같은 리스트가 두 번 반복됩니다. 이것을 이어 붙이기(concatenation)라고 합니다. 리스트에 숫자를 더하는 것은 아예 안 됩니다.

print(lst + 1)
TypeError: can only concatenate list (not "int") to list

(오류가 나면 실제로는 여러 줄의 오류 메시지가 나오는데, 여기서는 마지막 줄만 옮겼습니다. 아래의 다른 오류 예시도 마찬가지입니다.)

넘파이 배열을 쓰면 이 두 가지 문제가 모두 해결됩니다. 넘파이를 불러오고, 리스트를 np.array()에 넣어 배열을 만들어 보겠습니다.

import numpy as np

arr = np.array([1, 2, 3, 4, 5])
print(arr + 1)
print(arr * 2)
print(arr + arr)
[2 3 4 5 6]
[ 2  4  6  8 10]
[ 2  4  6  8 10]

배열에 1을 더하면 모든 원소에 1이 더해지고, 배열끼리 더하면 같은 자리의 원소끼리 더해집니다. 이렇게 원소마다 따로 계산하는 것을 원소별 연산(element-wise operation)이라고 합니다. 벡터의 덧셈이나 스칼라배를 생각하시면 됩니다.

배열 만들기

np.array() 말고도 배열을 만드는 함수가 여럿 있습니다. 자주 쓰는 것들은 다음과 같습니다.

함수 만드는 배열
np.zeros(shape) 모든 원소가 0인 배열
np.ones(shape) 모든 원소가 1인 배열
np.full(shape, value) 모든 원소가 value인 배열
np.arange(start, stop, step) start부터 stop 직전까지 step 간격의 수
np.linspace(start, stop, num) start부터 stop까지(포함) 같은 간격으로 num개의 수
np.eye(n) \(n \times n\) 단위행렬
np.random.random(shape) 0과 1 사이의 균등난수로 채운 배열

마지막 함수만 np.random.random처럼 길게 적은 데는 이유가 있습니다. 파이썬에 기본으로 들어 있는 random 모듈에도 random.random()이라는 함수가 있어서, 이름이 겹치지 않도록 넘파이의 random 하위 모듈 안에 들어 있는 것입니다. 파이썬 기본 random.random()은 난수를 하나만 만들지만, np.random.random()은 원하는 모양의 배열 전체를 난수로 채워 줍니다.

print(np.zeros(5))
print(np.arange(0, 10, 2))
print(np.linspace(0, 1, 5))
print(np.ones((2, 3)))
[0. 0. 0. 0. 0.]
[0 2 4 6 8]
[0.   0.25 0.5  0.75 1.  ]
[[1. 1. 1.]
 [1. 1. 1.]]

배열의 모양과 축

마지막 예의 np.ones((2, 3))은 2행 3열의 2차원 배열을 만들었습니다. 여기서 (2, 3)처럼 각 방향으로 원소가 몇 개씩 있는지를 나타낸 것을 배열의 모양(shape)이라고 합니다. 리스트를 넣으면 1차원 배열이, 리스트의 리스트를 넣으면 2차원 배열(행렬)이, 리스트의 리스트의 리스트를 넣으면 3차원 배열이 만들어집니다.

A = np.array([[1, 2, 3],
              [4, 5, 6]])
print(A)
print("모양:", A.shape)
[[1 2 3]
 [4 5 6]]
모양: (2, 3)

모양 (2, 3)의 첫 번째 숫자 2는 행의 개수, 두 번째 숫자 3은 열의 개수입니다. 넘파이에서는 이 각 방향을 축(axis)이라고 부르고, 앞에서부터 차례로 axis=0, axis=1, …이라고 번호를 붙입니다.

  • axis=0은 행 번호가 바뀌는 방향, 즉 위에서 아래로 내려가는 방향입니다.
  • axis=1은 열 번호가 바뀌는 방향, 즉 왼쪽에서 오른쪽으로 가는 방향입니다.

축은 뒤에서 볼 합계나 평균 같은 계산을 어느 방향으로 할지 정할 때 쓰입니다. 3차원 이상의 배열은 axis=2, axis=3, …이 차례로 더 붙는다고 생각하시면 됩니다.

시드: 다시 만들 수 있는 난수

혼자서 넘파이를 연습할 때는 랜덤하게 생성된 숫자, 즉 난수로 배열을 만들어 이것저것 해 보는 것이 편리합니다. 그런데 사실 컴퓨터가 만드는 난수는 진짜 무작위가 아니라 정해진 계산 규칙으로 만들어지는 유사 난수(pseudo-random number)입니다. 전부 그냥 정해져있는 수학 공식에 따라서 컴퓨터가 계산해서 뱉는, 그저 우리 눈에 보이기에 랜덤한 숫자라는거죠. 그리고 컴퓨터는 이 공식으로 랜덤한 숫자를 생성하기 위해서 계산의 출발점이 되는 값인 시드(seed)가 필요합니다. 같은 시드에서 출발하면 언제 어디서 실행하든 똑같은 난수가 나옵니다. 결국 그 시드를 시작으로, 랜덤한 숫자를 정해진 공식에 따라서 순차적으로 생성해서 뱉어내니까요.

np.random.seed(1557)
print(np.random.random(3))
np.random.seed(1557)         # 시드를 다시 초기화
print(np.random.random(3))   # 같은 시드에서 다시 시작
[0.56431542 0.89729768 0.43135233]
[0.56431542 0.89729768 0.43135233]

위의 코드는 시드를 설정하고, 그걸 통해서 랜덤한 숫자를 생성하는 과정입니다. 설명한대로 컴퓨터가 만드는 난수는 진짜 랜덤하게 뽑은 숫자가 아니라, 수학 공식에 시드값(위 코드에서는 1557)을 대입하여 순차적으로 계산한 값이기 떄문에, 보시다시피 공식의 시드값을 새로 입력하는 순간, 다시 처음으로 돌아가서 같은 숫자를 생성해냄을 알 수 있습니다. 만약 위 코드의 3번째 행(시드를 초기화하는 부분)을 지우고 실행하신다면, 당연히 시드가 초기화되지 않았으므로 그 이후에 생성되는 3개의 값들은 모두 위의 3개의 값들과 다른 형태가 됩니다.

이게 단점처럼 보일 수 있습니다. 진짜 랜덤한 숫자를 생성하지 못하는거니까요. 하지만 데이터 사이언스에서 이건 오히려 장점이 됩니다. 이 성질 덕분에 다른 사람도 내 분석을 그대로 다시 해 볼 수 있거든요. 난수는 이론적으로 랜덤한 값이기 떄문에, 만약 진짜 랜덤으로 생성되는 구조였다면, 그 랜덤으로 생성된 값으로 이런 저런 시도를 한 결과가 다른 사람들이 시도했을 때 똑같이 보장되지 않을 수 있습니다. 진짜 난수라면 내가 지금 생성한 난수들이랑, 다른 사람이 나중에 생성한 난수들이 거의 모든 경우 매우 다를테니까요. 하지만 컴퓨터가 생성하는 유사 난수는 오히려 진짜 난수가 아니기 떄문에, 다른 사람들도 시드만 알고 있다면 내가 지금 생성한 값들 추후에 똑같이 재현해낼 수 있습니다.

남들도 내가 했던거랑 똑같은 결과를 얻을 수 있다, 이건 데이터 사이언스에서 생각보다 많이 중요합니다. 그래서 이를 재현 가능성(Reproducibility)라고 이름까지 붙여서 중요하게 다루며, 재현 가능성은 후속되는 글에서 더 자세하게 다뤄집니다. 지금 단계에서는 이렇게 컴퓨터가 만드는 난수는 진짜 난수가 아니며, 시드에 의해 계산되는 결정론적인(정해진 수학적 알고리즘으로 계산되는) 유사난수이므로, 난수가 들어가는 코드를 논문이나 보고서에 실을 때는 시드를 함께 적는 것이 일반적이고, 혼자 연습할 때도 시드를 정해 두면 나중에 다시 확인하기 좋다 정도로 넘어가시면 됩니다.

참고로 이 사이트의 글들도 모두 재현 가능성을 위해 시드를 기본적으로 1557로 고정하고 있습니다.

그래서 컴퓨터가 정확하게 난수를 어떻게 생성해내는가?에 대한 이야기는 확률적 시뮬레이션에서 다뤄집니다. 물론 저 과목은 어느 정도 확률론적인 배경을 요구하기 떄문에 배경 지식이 없으시면 지금 보러 가셔도 이해가 안되실 가능성이 높습니다.

데이터 검사

이제 배열을 데이터 탐색에 써 보겠습니다. 학생 4명의 국어, 수학, 영어 점수가 다음과 같다고 해 보겠습니다. 행이 학생, 열이 과목입니다.

scores = np.array([[85, 72, 90],
                   [60, 95, 78],
                   [92, 88, 65],
                   [70, 64, 82]])

가장 먼저 할 일은 데이터가 제대로 들어왔는지 확인하는 것입니다. 배열은 자신에 대한 기본 정보를 속성(attribute)으로 가지고 있습니다.

print("자료형:", scores.dtype)
print("차원 수:", scores.ndim)
print("모양:", scores.shape)
print("원소 개수:", scores.size)
자료형: int64
차원 수: 2
모양: (4, 3)
원소 개수: 12

dtype은 배열에 담긴 값의 자료형입니다. 여기서는 정수(int64)이고, 소수가 섞여 있으면 보통 64비트 실수인 float64가 됩니다. 소수가 있어야 할 데이터가 정수로 들어와 소수점 아래가 잘려 나가지는 않았는지 확인할 때 유용합니다. ndim은 축의 개수, shape는 모양, size는 전체 원소 개수입니다. 이것만 봐도 데이터가 기대한 대로 들어왔는지 1차로 점검할 수 있습니다.

다음으로 2.2에서 본 요약 통계량을 계산해 보겠습니다. 아무것도 지정하지 않으면 배열 전체를 대상으로 계산합니다.

print("합:", scores.sum())
print("최솟값:", scores.min(), "최댓값:", scores.max())
print("평균:", round(scores.mean(), 2))
합: 941
최솟값: 60 최댓값: 95
평균: 78.42

여기에 axis를 지정하면 그 방향으로만 계산합니다. axis=0이면 위에서 아래로, 즉 같은 열 안에서 계산하므로 과목별 결과가 나오고, axis=1이면 왼쪽에서 오른쪽으로, 즉 같은 행 안에서 계산하므로 학생별 결과가 나옵니다.

print("과목별 평균:", scores.mean(axis=0))
print("학생별 평균:", scores.mean(axis=1).round(1))
print("과목별 최고 점수 학생:", scores.argmax(axis=0))
과목별 평균: [76.75 79.75 78.75]
학생별 평균: [82.3 77.7 81.7 72. ]
과목별 최고 점수 학생: [2 1 0]

argmax는 최댓값 자체가 아니라 최댓값이 몇 번째에 있는지를 알려 줍니다. 국어는 2번 학생, 수학은 1번 학생, 영어는 0번 학생이 가장 높은 점수를 받았다는 뜻입니다(파이썬은 0부터 셉니다). 이 밖에도 cumsum()은 앞에서부터 차례로 더해 나간 누적합을 계산해 주는데, 역시 axis로 방향을 정할 수 있습니다.

결측치 찾기

데이터 검사에서 무엇보다 중요한 것은 결측치(missing value), 즉 빠진 값을 찾는 일입니다. 넘파이에서는 빠진 값을 보통 np.nan(not a number)으로 나타냅니다. 이번에는 수학 점수 하나와 영어 점수 하나가 빠진 데이터를 생각해 보겠습니다.

data = np.array([[85.0, 72.0, 90.0],
                 [60.0, np.nan, 78.0],
                 [92.0, 88.0, np.nan],
                 [70.0, 64.0, 82.0]])

print(np.isnan(data))
print("결측치 개수:", np.isnan(data).sum())
[[False False False]
 [False  True False]
 [False False  True]
 [False False False]]
결측치 개수: 2

np.isnan()은 원래 배열과 같은 모양의 배열을 돌려주는데, nan이 있는 자리에는 True, 나머지 자리에는 False가 들어 있습니다. 여기에 sum()을 하면 True가 1, False가 0으로 계산되므로 결측치의 개수가 나옵니다.

결측치가 있는 채로 평균을 내면 어떻게 될까요?

print("과목별 평균:", data.mean(axis=0))
print("결측치를 빼고 낸 평균:", np.nanmean(data, axis=0).round(1))
과목별 평균: [76.75   nan   nan]
결측치를 빼고 낸 평균: [76.8 74.7 83.3]

nan이 하나라도 섞이면 계산 결과도 nan이 되어 버립니다. 결측치를 빼고 계산하려면 np.nanmean()처럼 앞에 nan이 붙은 함수를 쓰면 됩니다.

마스킹

결측치를 특정 값으로 채워 넣고 싶을 때는 다음과 같이 할 수 있습니다.

filled = data.copy()
filled[np.isnan(filled)] = 0.0
print(filled)
[[85. 72. 90.]
 [60.  0. 78.]
 [92. 88.  0.]
 [70. 64. 82.]]

배열의 대괄호 안에 숫자 인덱스가 아니라 True/False로 이루어진 배열을 넣었습니다. 이렇게 하면 True인 자리만 골라서 값을 바꾸거나 꺼내 올 수 있는데, 이를 마스킹(masking) 또는 불리언 인덱싱(boolean indexing)이라고 합니다. 위치를 직접 적는 대신 “조건을 만족하는 자리”를 지정하는 아주 강력한 방법입니다. 예를 들어 80점 이상인 점수만 꺼내는 것도 같은 방식입니다.

print(scores[scores >= 80])
[85 90 95 92 88 82]

다만 결측치를 0으로 채우는 것은 연습용일 뿐, 실제 분석에서는 조심해야 합니다. 시험을 안 본 학생의 점수를 0점으로 채우면 평균이 실제보다 낮아지고, 1.4에서 본 것처럼 왜 빠졌는지에 담긴 정보도 사라지기 때문입니다. 결측치를 어떻게 다룰지는 데이터와 질문에 따라 신중하게 정해야 하고, 실무에서는 보통 2.6에서 다룰 판다스의 기능을 씁니다.

배열로 계산하기

넘파이 배열은 수치 계산을 위한 구조이므로 수학 연산을 거의 모두 지원합니다. 사칙연산은 +, -, *, /를 그대로 쓰면 원소별로 계산됩니다. (같은 일을 하는 np.add(), np.subtract(), np.multiply(), np.divide() 같은 함수도 있습니다.) 두 배열의 모양이 다르면 브로드캐스팅(broadcasting)이라는 규칙에 따라 작은 배열을 늘려서 계산하는데, 처음의 arr + 1도 사실은 숫자 1을 배열 모양으로 늘려서 더한 것입니다. 자세한 규칙은 수학적 프로그래밍을 참고하시기 바랍니다.

통계 데이터를 다룰 때 자주 쓰는 지수와 로그도 원소별로 계산됩니다. np.exp()와 np.log()는 밑이 \(e\)이고, 밑이 10이나 2인 로그는 np.log10(), np.log2()를 씁니다.

v = np.array([1, 10, 100, 1000])
print(np.log10(v))
[0. 1. 2. 3.]

그런데 *가 원소별 곱셈이라면, 행렬의 곱셈은 어떻게 할까요? 넘파이는 행렬 곱셈을 위해 @라는 연산자를 따로 제공합니다.

M = np.array([[1, 2],
              [3, 4]])
x = np.array([1, 1])

print("원소별 곱 M * M:\n", M * M)
print("행렬 곱 M @ M:\n", M @ M)
print("행렬과 벡터의 곱 M @ x:", M @ x)
원소별 곱 M * M:
 [[ 1  4]
 [ 9 16]]
행렬 곱 M @ M:
 [[ 7 10]
 [15 22]]
행렬과 벡터의 곱 M @ x: [3 7]

이 밖에 역행렬, 행렬식, 고윳값처럼 선형대수에서 쓰는 계산들은 np.linalg 하위 모듈에 모여 있습니다. 배열의 모양을 바꾸는 reshape(), 행과 열을 맞바꾸는 전치 .T, 배열을 이어 붙이거나 쪼개는 함수들도 자주 쓰이니, 필요할 때 찾아 쓰시면 됩니다.

파일로 저장하고 불러오기

검사하고 손질한 데이터는 파일로 저장해 두어야 다음에 다시 쓸 수 있습니다. 넘파이 배열은 np.save()로 넘파이 전용 형식인 .npy 파일에 저장하고, np.load()로 다시 불러올 수 있습니다.

np.save("scores", scores)          # 같은 폴더에 scores.npy 가 만들어집니다
loaded = np.load("scores.npy")
print(loaded.shape, (loaded == scores).all())
(4, 3) True

파일은 지금 실행 중인 코드가 있는 폴더에 만들어지고, 불러올 때도 기본적으로 그 폴더에서 찾습니다. 주피터 노트북을 쓰신다면 왼쪽 파일 목록에 scores.npy가 새로 생긴 것을 볼 수 있습니다. (바로 안보인다면 한 5~10초 기다리시면 보일겁니다.)

텍스트 파일에서 불러오기

더 흔한 경우는 이미 있는 텍스트 파일에서 데이터를 읽어 오는 것입니다. 연습을 위해 먼저 작은 텍스트 파일을 하나 만들어 두겠습니다.

with open("data.txt", "w") as f:
    f.write("1 3 5\n7 9 11\n13 15 17\n")

np.loadtxt()에 파일 이름을 넣으면 파일을 읽어 배열로 돌려줍니다. 기본적으로 줄바꿈으로 행을 나누고, 공백으로 열을 나눕니다.

x = np.loadtxt("data.txt")
print(x)
[[ 1.  3.  5.]
 [ 7.  9. 11.]
 [13. 15. 17.]]

unpack=True를 넣으면 열별로 따로 나눠서 돌려줍니다. 여러 값을 한꺼번에 나눠 담는 것을 파이썬에서는 언패킹(unpacking)이라고 부르기 때문에 붙은 이름입니다.

a, b, c = np.loadtxt("data.txt", unpack=True)
print(a, b, c)
[ 1.  7. 13.] [ 3.  9. 15.] [ 5. 11. 17.]

열을 나누는 기준을 구분자(delimiter)라고 하는데, 쉼표로 열을 나눈 파일이라면 delimiter=","로 바꿔 줄 수 있습니다. 그런데 loadtxt는 꽤 예민해서, 파일 모양이 기대와 조금만 달라도 바로 오류를 냅니다. 예를 들어 공백으로 나뉜 위의 파일을 쉼표 기준으로 읽으려고 하면, 한 줄 전체인 "1 3 5"를 숫자 하나로 바꾸려다 실패합니다.

x = np.loadtxt("data.txt", delimiter=",")
ValueError: could not convert string '1 3 5' to float64 at row 0, column 1.

이럴 때는 np.genfromtxt()를 쓸 수 있습니다. 이 함수는 읽을 수 없는 부분을 만나면 멈추는 대신 그 자리를 nan으로 채웁니다.

x = np.genfromtxt("data.txt", delimiter=",")
print(x)
[nan nan nan]

오류는 안 났지만, 각 줄을 숫자 하나로 읽으려다 실패해서 세 줄이 각각 nan 하나가 되었습니다. 3행 3열이어야 할 데이터가 nan 세 개짜리 1차원 배열이 되어 버린 것입니다. 이처럼 데이터를 불러오는 과정에서도 결측치가 생길 수 있기 때문에, 파일을 읽은 다음에는 반드시 위에서 본 데이터 검사를 다시 해야 합니다. loadtxt처럼 바로 멈추는 쪽이 문제를 빨리 알아차리기에는 오히려 나을 때도 있습니다.

실무에서는 표 형태의 파일을 읽을 때 넘파이보다 판다스를 훨씬 많이 씁니다. 하지만 판다스도 내부적으로는 넘파이 배열 위에서 돌아가기 때문에, 여기서 본 원리를 알아 두면 판다스를 이해하기가 훨씬 쉬워집니다.

정리

  • 넘파이 배열은 한 가지 종류의 숫자만 담아 빠르게 계산하고, 연산이 원소별로 이루어집니다.
  • 배열의 모양(shape)은 각 축의 원소 개수이고, axis=0은 위에서 아래로, axis=1은 왼쪽에서 오른쪽으로 가는 방향입니다.
  • dtype, shape, sum(), mean(axis=...) 등으로 데이터를 검사하고, np.isnan()과 마스킹으로 결측치를 찾고 다룹니다.
  • *는 원소별 곱셈, @는 행렬 곱셈입니다.
  • np.save()와 np.load()로 배열을 저장하고 불러오며, 텍스트 파일은 np.loadtxt()나 np.genfromtxt()로 읽습니다.

이제 배열에 담긴 데이터를 그림으로 그려 볼 차례입니다. 다음 글에서는 좋은 그림이란 무엇인지부터 생각해 보고, 맷플롯립으로 직접 그래프를 그려 보겠습니다.
